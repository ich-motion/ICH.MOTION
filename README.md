Работа моушн-дизайнером в маркетинге научила меня многим вещам, но главное: After Effects — твой лучший друг. Однако это такой друг, у которого есть много проблем.

Для решения этих проблем я и создал **ICH.MOTION**. Это бесплатный и общедоступный CEP-плагин, который изначально задумывался как удобный инструмент для создания субтитров, а в итоге превратился из простого JSX-скрипта в полноценный плагин.

## ✨ Ключевые возможности
1. **Safe Zones:** Создание сейвзоны для композиций с помощью шаблонов и заданных настроек универсально, или под конкретную платформу + опциональное добавление гайдлайнов под разные соотношения сторон.
2. **Resize:** Изменение размеров композиций с помощью шаблонов и настроект
3. **Comps Name:** Удобный нейминг и ренейминг композиций.
4. **TrueDuplicate:** Создание реальных дубликатов композиций и всех вложенный прекомпозиций.
5. **Subs:** Профессиональный (табличный) редактор субтитров с возможностью транскрибации через Whisper.
6. **Presets Manager:** Удобный поиск своих пресетов анимации, базовые анимации для субтитров и возможность применения своих пресетов с начала текстовых слоев с поддержкой импорта .mogrt файлов.
7. **ASK AI:** Чат с Gemini (для free-tier аккаунтов) или моделями с OpenRouter прямо в AE + роль «AE Терминатор», который умеет понимать и править композиции. Так же можно использовать как MCP.

## 🚀 Установка
1. Скачайте последний `.zxp` файл из релизов.
2. Установите его с помощью [ZXPInstaller](https://aescripts.com/learn/post/zxp-installer), либо разархивировать по пути:
```text
C:\Program Files (x86)\Common Files\Adobe\CEP\extensions
```
3. Перезапустите After Effects и откройте панель через `Window -> Extensions -> ICH.MOTION`.

## 🤖 Настройка AI
Для работы вкладки **ASK AI** потребуется бесплатный ключ из Google AI Studio или OpenRouter.

## 🎙️ Настройка Auto SRT (Whisper)
Для локальной генерации субтитров:
1. В настройках укажите папку для **Faster-Whisper-xxl**.
2. Плагин предложит скачать файл `faster-whisper-xxl.exe`.
3. Вся транскрибация будет проходить полностью локально на вашей видеокарте или процессоре!
